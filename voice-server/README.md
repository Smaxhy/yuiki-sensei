# Yuki voice server (free)

Runs the official VOICEVOX engine so Yuki can speak **all** Japanese in Himari (冥鳴ひまり) or Ryusei (青山龍星).

## Put it on a free Hugging Face Space
1. Sign up at huggingface.co (free).
2. Go to huggingface.co/new-space → name `yuki-voice` → SDK **Docker** → **Blank** → hardware **CPU basic (free)** → Create.
3. Files → Add file → Create a new file → name it `Dockerfile` → paste the Dockerfile from this folder → Commit.
4. When the Space says **Running**, open Yuki → Me → Voice → **Himari & Ryusei**, type `yourname/yuki-voice`, tap **Save & test**.

Voices: VOICEVOX:冥鳴ひまり, VOICEVOX:青山龍星
